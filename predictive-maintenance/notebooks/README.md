
# Research Notebooks

This directory contains Jupyter notebooks for data exploration, preprocessing, clustering, evaluation, and reproducibility.

## Available Notebook

- [`predictive_maintenance_clustering.ipynb`](predictive_maintenance_clustering.ipynb) — analysis of operating-condition patterns in the AI4I 2020 Predictive Maintenance Dataset using K-Means clustering.

The notebook documents the methodology, experimental settings, evaluation metrics, statistical analysis, and limitations of the research.

## Reproducibility

Open the notebook in Jupyter and run the cells in order. See the project README for dataset acquisition instructions and the required Python environment.
