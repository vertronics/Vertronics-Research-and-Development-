# Predictive Maintenance Research

## Overview

This project investigates the use of unsupervised machine learning to identify operating-condition patterns in the AI4I 2020 Predictive Maintenance Dataset.

The research explores whether clustering can reveal meaningful groupings in equipment operating data and evaluates the potential relevance of those patterns to industrial monitoring and maintenance.

## Research Objectives

- Apply K-Means clustering to equipment operating data.
- Evaluate clustering quality using appropriate statistical metrics.
- Examine the relationship between discovered clusters and recorded failure labels without using those labels to train the clustering model.
- Assess practical applications, limitations, and opportunities for further research.

## Methodology

The study uses data preparation, feature analysis, unsupervised clustering, and quantitative evaluation. Findings will be documented alongside the code and visualizations needed to reproduce the analysis.

## Dataset

The study uses the AI4I 2020 Predictive Maintenance Dataset from the UCI Machine Learning Repository.

Dataset source: https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset

Refer to the dataset's own terms before redistributing its files.

## Research Scope and Limitations

This is an exploratory study using a synthetic dataset. Clustering results do not, by themselves, establish a validated predictive-maintenance system or demonstrate real-world industrial performance.
