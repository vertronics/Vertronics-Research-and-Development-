# Research Figures

This directory contains visualizations generated by the predictive maintenance clustering study.

## Planned Contents

- Operating-condition distributions.
- K-Means cluster visualizations.
- Cluster comparison plots.
- Visual summaries of machine-failure rates across clusters.

## Reproducibility

Figures should be generated from the analysis in [`predictive_maintenance_clustering.ipynb`](../notebooks/predictive_maintenance_clustering.ipynb).

Only figures verified against the research notebook should be published here.

The figure files will be added after the final visualizations have been reviewed.
