# Dataset Documentation

## Dataset Used

**AI4I 2020 Predictive Maintenance Dataset**

Source: UCI Machine Learning Repository

Dataset page: https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset

## Purpose

This dataset provides equipment operating measurements and failure-related information for research into predictive maintenance and industrial machine learning.

## Data Handling

- Obtain the dataset from its original source.
- Review the dataset documentation and applicable terms before use or redistribution.
- Keep raw data separate from processed data and generated results.
- Document preprocessing, feature selection, and any transformations applied during analysis.
- Do not treat synthetic dataset findings as proof of performance on real industrial equipment.

## Reproducibility

The research notebooks will document the data-loading procedure, preprocessing steps, selected features, and evaluation methods.

The dataset itself is not included in this directory by default. Follow the source link above to obtain it.
