# Research Results

This directory contains the quantitative outputs generated by the predictive maintenance clustering study.

## Planned Contents

- Clustering evaluation metrics.
- Cluster-size summaries.
- Machine-failure rate summaries by cluster.
- Statistical test results examining the association between cluster membership and recorded failures.

## Reproducibility

The results should be traceable to the analysis in [`predictive_maintenance_clustering.ipynb`](../notebooks/predictive_maintenance_clustering.ipynb).

Only results verified against the research notebook should be published here.

The numerical result files will be added after the final analysis outputs have been checked.
